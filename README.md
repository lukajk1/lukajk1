## Hi, I'm Luka

CS student @ Cal State East Bay working on graphics, VR, and real-time systems.

### Projects

**[4D Chess](https://play4dchess.vercel.app/)** — chess on a 4×4×4×4 hypercube,
rendered with a true 4D→3D perspective projection with rotation across all six
planes. Other existing implementations flatten the hypercube into a grid of 2D boards in standard 3D space;
this one keeps the geometry intact so the tesseract structure is visible. Built in JavaScript with Three.js.
→ [source](https://github.com/lukajk1/4D-chess) · [play it](https://play4dchess.vercel.app/)

**[ARKVAIN](https://store.steampowered.com/app/4390190/ARKVAIN/)** — a competitive
arena shooter built in Unity, currently in development for Steam release. The
interesting part is the networking: client-side prediction with server rollback,
authoritative hit validation, and P2P lobbies over the Steamworks API. Written in
C# on top of PurrNet.
→ [source](https://github.com/lukajk1/afps-public) · [trailer](https://www.youtube.com/watch?v=W1TRvJojrtw)
